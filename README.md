# המילון התורני 3.0

מילון מותאם ל-Microsoft Word. הוא מונע מוורד לסמן כשגיאה מילים מהתנ"ך, מהמשנה, מהתלמוד הבבלי ומהתלמוד הירושלמי ומספרים נוספים, וגם ראשי תיבות (כמו רש"י, חז"ל).

## הורדה

**[להורדת הגרסה האחרונה](https://github.com/elicohen8565-hue/milon-torani-3.0/releases/latest/download/Milon-Torani-3.0.exe)**

כל הגרסאות נמצאות ב[דף הגרסאות](https://github.com/elicohen8565-hue/milon-torani-3.0/releases).

## התקנה

1. סגרו את וורד.
2. פתחו את הקובץ שהורדתם.
   אם ווינדוס מציג "Windows protected your PC", לחצו "More info" ואחר כך "Run anyway".
3. בחרו מילון:
   - **בסיסי**: תנ"ך, משנה, בבלי וירושלמי.
   - **מורחב**: גם ראשונים, אחרונים, הלכה, מדרש ועוד.

   אפשר להוסיף גם **חיבור תורני**, כלומר מילים עם אותיות חיבור כמו בארמית: דהעניין, ודלא וכדומה.
4. לחצו **התקן**. בסוף התוכנה בודקת בעצמה שוורד מזהה את המילים.

**דרישות:** Windows 10 או 11, ו-Microsoft Word בגרסה 2016 ומעלה (כולל Microsoft 365). לא צריך הרשאות מנהל.

## עריכת מילים

מצאתם במילון מילה שגויה, או חסרה בו מילה? לוחצים **עריכת מילים**.

1. מחפשים את המילה ברשימה של כל המילים במילון.
2. לוחצים **תקן איות** או **הסר מהמילון**. מילה חדשה מוסיפים בצד שמאל.
3. לוחצים **שמור ועדכן את וורד**.

השינויים נשמרים במחשב שלכם, ונשארים גם אחרי כל עדכון של המילון.

אחרי השמירה אפשר לשלוח את השינויים כהצעה לשיפור המילון לכולם. ההצעה נפתחת כאן, ב[רשימת ההצעות](https://github.com/elicohen8565-hue/milon-torani-3.0/issues), בגלוי, בלי שם ובלי פרטים מזהים.

## הסרה

לוחצים **הסר מוורד** באותה תוכנה. מילים שהוספתם בעצמכם לוורד נשמרות, וגם השינויים שעשיתם ב"עריכת מילים" (הם יחזרו בהתקנה הבאה).
